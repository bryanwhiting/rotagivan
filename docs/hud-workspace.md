# HUD workspace

The HUD settings page has three panes.

- **HUD list (left).** Default taps (the base tap layer that has no on-screen
  HUD), Main HUD, every HUD placed around it, and their nested HUDs indented
  under the HUD that opens them. Built-in defaults sit at the bottom. **New HUD**
  adds a blank, template or built-in HUD at the next free map position.
- **Canvas (center).** The live HUD preview and the HUD map. Click a tile to
  select it, drag tiles to swap, and click a neighboring HUD to edit it. The
  breadcrumb returns from nested HUDs. The gear holds theme and navigation
  options.
- **Inspector (right).** With a tile selected: its action, app-window option,
  nested HUD and deep swipe commands, transfer and removal. With no tile
  selected: the HUD's name, map position, slot count, contents, hotkeys and
  gestures, bookmark import and removal. Names save on Return or when focus
  leaves the field.

Preview clicks never launch apps or run actions. The HUD page needs a wider
window (1100 pt minimum), so the settings sidebar shows icons only there.
